**Explain the difference between matrix multiplication and convolution.**

Matrix multiplication and convolution are two distinct operations used in linear algebra and signal processing. Let's break down the key differences between them.

**Matrix Multiplication**

Matrix multiplication combines complete rows of one matrix with complete columns of another. The inner dimensions must match. For example, if we have two matrices A and B with shapes (3x4) and (4x5) respectively, the resulting matrix C will have a shape of (3x5).

**Convolution**

Convolution applies a smaller kernel to local input regions while the kernel moves across spatial positions. In other words, it slides the kernel over the input matrix, performing a dot product at each position. The kernel combines values from one local input region at a time.

**Key differences**

1. **Alignment**: Matrix multiplication aligns complete rows of one matrix with complete columns of another. Convolution, on the other hand, aligns the kernel with local input regions.
2. **Movement**: Matrix multiplication does not move any elements. Convolution moves the kernel across spatial positions.
3. **Output structure**: Matrix multiplication produces a new matrix with the same number of rows as the first matrix and the same number of columns as the second matrix. Convolution produces a new matrix with a different shape, depending on the kernel size and input matrix size.

**Example**

Let's consider a simple example using the MatrixComputationTool. We have an input matrix:

```
1  2  3
4  5  6
7  8  9
```

And a kernel:

```
1  0
0  1
```

At the top-left position, the kernel combines values from the input matrix as follows:

```
(1x1) + (2x0) + (4x0) + (5x1) = 6
```

The full valid output is:

```
6  8
12 14
```

**Evidence used**

* Matrix multiplication uses row-by-column dot products and requires matching inner dimensions.
* Convolution applies one kernel repeatedly to local spatial regions.
* The kernel combines values from one local input region at a time.
* The example valid output is [[6, 8], [12, 14]].
