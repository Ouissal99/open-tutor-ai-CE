**Convolution output size explained again**

The important correction is that a valid convolution does not automatically preserve the input size. The output depends on the input size, kernel, padding, and stride.

**Formula**

`O = floor((N + 2P - K) / S) + 1`

Where:

- `N` is the input size.
- `K` is the kernel size.
- `P` is the padding.
- `S` is the stride.

**Verified example**

- Input size: `N = 5`
- Kernel size: `K = 3`
- Padding: `P = 0`
- Stride: `S = 1`

`O = floor((5 + 2(0) - 3) / 1) + 1`

`O = 3`

Therefore, the verified spatial output is **3 × 3**.

A common mistake is to assume that the output keeps the same size as the input. That happens only under specific padding and stride settings.

**Evidence used**

- The convolution output-size formula is O = floor((N + 2P - K) / S) + 1.
- For input 5x5, kernel 3x3, stride 1, and padding 0, the verified output shape is 3x3.
