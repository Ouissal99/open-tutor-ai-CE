**Visualizing Matrix Multiplication with a Small 2x2 Example**

Matrix multiplication is a fundamental operation in linear algebra. It combines rows of the first matrix with columns of the second matrix to produce a new matrix.

Let's consider a small 2x2 example to illustrate this concept. We have two matrices:

A = [[1, 2], [3, 4]]
B = [[5, 6], [7, 8]]

To get each value in the result matrix C, we take one row from A and one column from B.

**Top-left value C[1,1]:**

row 1 of A · column 1 of B = (1×5) + (2×7) = 19

**Top-right value C[1,2]:**

row 1 of A · column 2 of B = (1×6) + (2×8) = 22

**Bottom-left value C[2,1]:**

row 2 of A · column 1 of B = (3×5) + (4×7) = 43

**Bottom-right value C[2,2]:**

row 2 of A · column 2 of B = (3×6) + (4×8) = 50

So the result is:

C = [[19, 22], [43, 50]]

This example demonstrates how matrix multiplication works with small matrices. The result is obtained by performing row-by-column dot products between the input matrices.

**Evidence used:**

* Matrix multiplication computes each result cell as a row-by-column dot product.
* For A = [[1, 2], [3, 4]] and B = [[5, 6], [7, 8]], the result is [[19, 22], [43, 50]].
