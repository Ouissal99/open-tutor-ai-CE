**Visualizing Convolution using a 3x3 Input and a 2x2 Kernel**

Convolution is a process that applies a small matrix called a kernel over an input matrix by sliding it across local regions. Let's use a simple example to understand how it works.

**Step 1: Define the Input Matrix and the Kernel**

The input matrix is a 3x3 matrix:
```
1  2  3
4  5  6
7  8  9
```
The kernel is a 2x2 matrix:
```
1  0
0  1
```
**Step 2: Slide the Kernel over the Input Matrix**

We will slide the kernel over the input matrix, aligning it with one local patch at a time. Let's start with the top-left position.

**Top-Left Position**

The kernel is aligned with the top-left patch of the input matrix:
```
1  2  3
4  5  6
7  8  9
```
The corresponding values are multiplied and then summed to produce one output value:
```
(1x1) + (2x0) + (4x0) + (5x1) = 6
```
**Full Valid Output**

The full valid output matrix is:
```
6  8
12 14
```
This example helps learners see how a local input patch is transformed into an output value.
