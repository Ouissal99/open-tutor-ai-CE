**Kernel Movement Explanation**

Let's visualize how a kernel moves over an input matrix. Imagine we have a 3x3 input matrix:

```
1  2  3
4  5  6
7  8  9
```

And a 2x2 kernel:

```
1  0
0  1
```

The kernel will move over the input matrix, one position at a time, multiplying the kernel values with the corresponding input patch values and summing the products to produce one output value.

**Step-by-Step Visual Explanation**

1. The kernel starts at the top-left position of the input matrix.
2. The kernel values are multiplied with the corresponding input patch values:
   - (1x1) + (2x0) + (4x0) + (5x1) = 6
3. The kernel moves one position to the right.
4. The kernel values are multiplied with the corresponding input patch values:
   - (2x1) + (3x0) + (5x0) + (6x1) = 8
5. The kernel moves one position down.
6. The kernel values are multiplied with the corresponding input patch values:
   - (4x1) + (5x0) + (7x0) + (8x1) = 12
7. The kernel moves one position to the right.
8. The kernel values are multiplied with the corresponding input patch values:
   - (5x1) + (6x0) + (8x0) + (9x1) = 14

The full valid output matrix is:

```
6  8
12 14
```

- The kernel combines values from one local input region at a time.
