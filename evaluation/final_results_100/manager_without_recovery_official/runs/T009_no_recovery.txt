Topic-consistent support for same convolution:
- Same convolution chooses padding so the output spatial dimensions follow the same-size target.
- With stride 1 and an odd kernel size K, padding P = (K - 1) / 2 preserves the input height and width.
- More generally, same padding is selected according to the input size, kernel, and stride.
